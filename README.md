# OneRoof Venture (ORV)

Welcome to the OneRoof Venture project repository!

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm.

### Installation & Setup

1. Navigate to the web application directory:
   ```bash
   cd orv/webapp
   ```

2. Install dependencies (if needed):
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## Project Structure
- `orv/webapp/`: Main React + Vite web application built with GSAP animations.
